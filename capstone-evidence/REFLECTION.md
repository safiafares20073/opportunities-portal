# Capstone Project — Personal Reflection

**Project:** Opportunities Portal for Yemeni Students  
**Course:** Google Antigravity  
**Date:** October 22, 2026

## What I Learned

Developing the Opportunities Portal helped me understand that building an application with AI coding agents requires more than writing prompts. It involves defining clear requirements, reviewing implementation plans, verifying results, and making informed decisions throughout development.

My goal was to create a practical platform that helps Yemeni students discover verified educational opportunities, particularly those who face difficulties with internet connectivity. Throughout the project, I learned how to translate user needs into functional features and evaluate whether the application actually meets those needs.

## Where Did the Agent Make Mistakes?

One important issue occurred during mobile responsiveness testing. An automated test reported that the interface worked correctly at a width of 360 pixels, but the actual browser viewport was 440 pixels. This showed me that a successful test result is not always sufficient evidence.

I also encountered translation issues where some dynamically generated interface messages remained in Arabic after switching to English. These problems required additional review and corrections.

## When Did My Review Make a Difference?

My review was especially valuable during testing. I questioned the reported mobile test result, checked the actual screen dimensions, and verified the layout again.

I also tested the favorites feature and confirmed that saved opportunities remained available after refreshing the page. After publishing the application on GitHub Pages, I tested its offline functionality to verify that users could access cached information without an internet connection.

These checks helped me identify problems that automated reports alone did not fully address.

## What Would I Do Differently?

In a future project, I would define more precise acceptance criteria before implementation, especially for browser dimensions, multilingual content, and offline behavior.

I would also organize implementation plans, approvals, screenshots, and test results from the beginning rather than collecting evidence near the submission deadline.

Most importantly, I would continue treating AI-generated code and test reports as outputs that require independent verification.

## Conclusion

This project strengthened my understanding of agent-assisted development, practical testing, debugging, version control, and deployment. My most important lesson is that AI agents can accelerate development, but the developer remains responsible for the quality, reliability, and usefulness of the final application.
